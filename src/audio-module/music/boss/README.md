# Boss

A low minor pedal, chromatic motif, and heavy pulse mark a major encounter.
The stereo output loops after four bars per round.

`cyberia-audio music boss --record`

| Parameter | Default | Range |
|---|---:|---:|
| sampleRate | 44100 | 22050–96000, integer |
| volume | 0.8 | 0–1 |
| bpm | 120 | 90–160 |
| rounds | 1 | 1–4, integer |
