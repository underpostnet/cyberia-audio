# Drop

A short descending impact marks loot creation or collection.
The seed controls the impact noise. The output is mono and does not loop.

`cyberia-audio sfx drop --record`

| Parameter | Default | Range |
|---|---:|---:|
| sampleRate | 44100 | 22050–96000, integer |
| volume | 0.7 | 0–1 |
| duration | 0.28 | 0.1–1 seconds |
| seed | 29 | 0–4294967295, integer |
